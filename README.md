# Vscan

Vscan is a modern web application built with [Next.js](https://nextjs.org/), designed to provide a rich, interactive user interface. It leverages the latest web technologies to deliver a fast and responsive experience.

## Tech Stack

This project is built using a powerful modern stack:

- **Framework**: [Next.js 16](https://nextjs.org/) (Pages Router)
- **UI Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Components**: [HeroUI](https://heroui.com/) (`@heroui/react`)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Charts & Data Visualization**: [Recharts](https://recharts.org/)

## Features

- **Modern UI/UX**: Utilizes HeroUI and Framer Motion for beautiful, accessible, and highly interactive components.
- **Data Visualization**: Includes Recharts for rendering complex data and metrics seamlessly.
- **Fast Performance**: Next.js and React 19 deliver an optimized, fast-loading user experience.

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (version 20 or later recommended) installed on your machine.

### Installation

1. Clone the repository and navigate into the project directory:
   ```bash
   cd vscan
   ```

2. Install the dependencies:
   ```bash
   npm install
   ```

### Running the Development Server

Start the development server by running:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result. You can start editing the pages in `src/pages` and the components in `src/components`. The page auto-updates as you edit the files.

## Scripts

- `npm run dev`: Starts the Next.js development server.
- `npm run build`: Builds the application for production usage.
- `npm run start`: Starts a Next.js production server.
- `npm run lint`: Runs ESLint to check for linting errors.
